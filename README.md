Bigram Language Model - The Wizard of Oz Edition

This project implements a simple Bigram Language Model (LLM) using PyTorch, trained on the classic novel The Wonderful Wizard of Oz by L. Frank Baum. The goal is to demonstrate how basic language modeling works by predicting the next character (or token) based on the previous one.


---

Features

Character-level Bigram Language Model

Simple PyTorch implementation from scratch

Trained on The Wizard of Oz text corpus

Generates new text samples based on learned bigram probabilities

Educational & minimalistic code structure
